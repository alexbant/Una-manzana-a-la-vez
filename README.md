🐍 Juego de la Serpiente

Un juego clásico de la serpiente desarrollado como práctica estudiantil para aprender y mejorar mis habilidades en desarrollo web.

🎮 Descripción

El objetivo del juego es controlar la serpiente, recoger la comida y conseguir la mayor puntuación posible sin chocar contra las paredes o contra el propio cuerpo.

🛠️ Tecnologías utilizadas

HTML

CSS

JavaScript

🚀 Cómo jugar

Abre el juego en tu navegador.

Utiliza los controles disponibles para mover la serpiente.

Recoge la comida para aumentar tu puntuación.

¡Intenta conseguir la mayor puntuación posible!

📚 Propósito del proyecto

Este proyecto fue creado con fines educativos para practicar conceptos básicos de desarrollo web y programación con JavaScript.
